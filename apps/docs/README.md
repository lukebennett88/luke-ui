# docs

Documentation app for the Luke UI design system.

Visible UI uses Luke UI components and docs-local Vanilla Extract styles. Fumadocs provides MDX,
page-tree, search data, and type generation only. See
[DOCUMENTATION.md](../../docs/DOCUMENTATION.md#docs-app-architecture).

## Commands

Run from the repository root:

```bash
pnpm run dev:docs
pnpm run build:docs
pnpm run check
```
