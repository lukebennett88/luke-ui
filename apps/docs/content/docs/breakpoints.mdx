---
title: Breakpoints
description: Change layout at named viewport widths with responsive layout properties.
---

Luke UI defines six breakpoint keys for responsive layout. `Box` layout properties accept a value at
each key. Choose a breakpoint when content needs a deliberate layout change.

Read [Layout](/layout) for the full layout API.

## Breakpoints

| Breakpoint | Minimum viewport width |
| ---------- | ---------------------- |
| `initial`  | 0px (base)             |
| `small`    | 640px                  |
| `medium`   | 768px                  |
| `large`    | 1024px                 |
| `xlarge`   | 1280px                 |
| `xxlarge`  | 1536px                 |

Each breakpoint is a fixed constant, not a theme token. A custom theme cannot change these widths.

Every breakpoint is a minimum width. There is no maximum width or range condition. For example, a
value set at the `small` breakpoint will also apply at the next medium (and above), unless a later
breakpoint overrides it.

## Responsive values

Pass a direct value when a layout property stays constant. Pass an object keyed by breakpoint when
it changes. Values cascade up from `initial`, so specify only the changes.

```tsx
<Box display="flex" flexDirection={{ initial: 'column', medium: 'row' }}>
	{children}
</Box>
```

## When to use a responsive value

Set a responsive value when the layout needs a deliberate change. Prefer intrinsic wrapping when the
content can adapt without a breakpoint.
