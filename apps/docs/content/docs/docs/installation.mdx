## Install Luke UI

Install Luke UI, React Aria Components, and a theme. Luke UI uses the application's React Aria
Components instance so shared contexts remain compatible. Luke UI's type declarations need
TypeScript 5.8 or later. This guide uses the Tactile theme.

```bash
pnpm add @luke-ui/react @luke-ui/theme-tactile react-aria-components
```

## Set up the theme

Import `@luke-ui/react/stylesheet.css` and the theme's `stylesheet.css` at your application root.
Import the theme's `fonts.css` to load its Inter font. Then set the theme's identity class on
`<html>` and `rootClassName` on `<body>`.

<SourceCodeBlock src="theming/getting-started" />

The theme stylesheet supplies the semantic variables. `rootClassName` adds the reset and base
typography.

## Use components

Import each component from its package path.

<SourceCodeBlock src="overview/welcome" />

Components that use icons need `Provider` at the application root. Pass it the URL for
`@luke-ui/react/spritesheet.svg`. See [Iconography](/docs/iconography#set-up-the-spritesheet) for
bundler setup.

## Change the theme

Paper, in `@luke-ui/theme-paper`, uses the same component APIs with a flatter visual treatment.
Install it, then import its stylesheets and set its identity class instead of Tactile's.

<SourceCodeBlock src="overview/paper-theme" />

Without `data-color-mode`, the theme follows the system colour mode. Read
[Applying a theme](/docs/applying-a-theme#choose-a-colour-mode) to set a mode.
