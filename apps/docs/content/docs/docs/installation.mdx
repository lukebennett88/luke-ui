## Install Luke UI

Install Luke UI, React Aria Components, and a theme. Luke UI uses the application's React Aria
Components instance so shared contexts remain compatible. Luke UI's type declarations need
TypeScript 5.8 or later. This guide uses the Tactile theme.

```bash
pnpm add @luke-ui/react @luke-ui/theme-tactile react-aria-components
```

## Set up the theme

The theme's identity class goes on `<html>`, and it must be there before the first paint. How you
set it depends on whether React renders the whole document.

Luke UI's shared stylesheet styles the document itself, so no root class is needed. It paints
`<body>` with the theme's surface, text colour, and body font, and portals rendered into `<body>`
inherit them. Read [Styling](/docs/styling#set-up-static-styles) for what else it changes.

### Single-page apps

In a Vite app, or any app that mounts React into an existing page, set the identity class in
`index.html`:

```html
<!doctype html>
<html class="luke-ui-theme-tactile" lang="en">
	<head>
		<meta charset="UTF-8" />
		<meta name="viewport" content="width=device-width, initial-scale=1.0" />
		<title>My app</title>
	</head>
	<body>
		<div id="root"></div>
		<script type="module" src="/src/main.tsx"></script>
	</body>
</html>
```

Import the stylesheets in the entry module. `fonts.css` loads the theme's Inter font. Leave it out
if you load Inter another way.

## Change the theme

Paper uses the same component APIs with a flatter visual treatment. To use it, install
`@luke-ui/theme-paper`, import its `stylesheet.css` and `fonts.css` instead of Tactile's, and set
`luke-ui-theme-paper` on `<html>`. Each theme package exports its class as `themeClassName`.

Without `data-color-mode`, the theme follows the system colour mode. Read
[Applying a theme](/docs/applying-a-theme#choose-a-colour-mode) to set a mode.
