## Install Luke UI

Install Luke UI and React Aria Components. Luke UI uses the application's React Aria Components
instance so shared contexts remain compatible.

```bash
pnpm add @luke-ui/react react-aria-components
```

## Set up the theme

Import `@luke-ui/react/stylesheet.css` and one theme stylesheet at your application root. This guide
uses Tactile. To use Paper, import `@luke-ui/react/themes/paper/stylesheet.css` instead.

Apply `rootClassName` to an element you own, such as the application shell. The theme stylesheet
supplies the semantic variables. `rootClassName` adds the reset and base typography.

## Change the theme

Tactile is the default bundled theme. Paper uses the same component APIs with a flatter visual
treatment. Switch which theme stylesheet you import to change the theme.

<SourceCodeBlock src="overview/paper-theme" />

Set `data-color-mode="light"` or `data-color-mode="dark"` on a themed element when the application
must use a specific mode. Without it, Luke UI follows the system preference.

## Optional: set up `xstyle`

`xstyle` is optional. Skip this step if you never override a component style beyond its supported
props — you need no StyleX compiler at all.

If you use `xstyle`, install `@stylexjs/stylex` as a dependency and a StyleX compiler as a dev
dependency. Your application imports `@stylexjs/stylex` directly, and pnpm isolates dependencies, so
it cannot use the copy Luke UI installs for its own runtime. Declare it yourself. The full install
for an application that authors `xstyle` is:

```bash
pnpm add @luke-ui/react react-aria-components @stylexjs/stylex
pnpm add -D @babel/core @stylexjs/babel-plugin
```

The compiler alone does not complete the setup. Your build must run the transform, collect the
extracted rules, emit them into a dedicated `xstyle` cascade layer between `recipes` and
`components`, and declare the combined layer order before loading the stylesheets. Read
[Styling](/docs/styling#give-xstyle-its-own-layer) for the bundler integration and the required
layer order.
