## Typography

Each type style is five tokens: family, size, weight, line height, and letter spacing. Render text
with `Text` or `Heading`, which also apply the style's trim. Use these tokens only when you need an
element those components cannot render. Read [Typography](/docs/typography#typography-styles) to
choose a style.

## Space

Use the space scale for `gap`, `padding`, and `margin`. The number in each key is its pixel value at
a 16px root. The token is emitted in `rem`. Read [Layout](/docs/layout#responsive-values) for
breakpoint keys and how spacing values cascade.

## Depth and finish

Depth places a surface above or within the interface. Menus and dialogs both use `surface.overlay`.
A menu adds `depth.floating`, and a dialog adds `depth.overlay`. A control finish is the face of a
solid control fill, such as a solid button.

Luke UI components already apply depth and finish for their own states. Use these tokens only for
custom surfaces you own.

## Motion

Choose a treatment: each pairs a duration with its easing. Each treatment table includes an Animate
switch in the group header. Duration and easing samples share a one-second cycle so the loops stay
aligned. Duration crossings take that token’s duration within the half-cycle; easing samples use the
same rest-and-cross pattern with that timing function on the travel segments. Turn Animate off to
hold the dots still, or on again to restart that table in sync.

- `feedback` covers an in-place state change, such as hover, focus, or selection.
- `enter` covers an element or an overlay that enters the interface.
- `exit` covers an element or an overlay that leaves the interface.

Use `vars.motion.<treatment>.duration` and `vars.motion.<treatment>.easing` together. Do not mix
leaves from different treatments.
