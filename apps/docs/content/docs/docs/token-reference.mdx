## Typography

Each type style is five tokens. Render text with `Text` or `Heading`, which also apply the style's
trim, and use these tokens for an element they cannot render. Read
[Typography](/docs/typography#typography-styles) to choose a style.

<TypeStyleTable />

The families and weights stay public for code surfaces and weight overrides.

<FontFamilyAndWeightTokens />

## Space

Space is one scale for `gap`, `padding`, and `margin`. The number in each key is its value in pixels
at a 16px root, and the token is emitted in `rem`. Read [Layout](/docs/layout#responsive-values) for
breakpoint keys and how spacing values cascade.

<SpaceTokens />

## Radius

Radius has five roles. Choose the role that matches the element you round, such as `control` for an
input or `surface` for a card.

<RadiusTokens />

## Depth and finish

Depth places a surface above or within the interface. Menus and dialogs both use `surface.overlay`.
A menu adds `depth.floating`, and a dialog adds `depth.overlay`. A control finish is the face of a
solid control fill, such as a solid button.

Components already apply depth and finish to their own states. Use these tokens only for custom
surfaces.

<DepthAndFinishTokens />

<InteractionTokens />

## Motion

Each duration is named for the role the movement plays. Hover or focus a duration to play it.

- `feedback` covers an in-place state change, such as hover, focus, or selection.
- `enter` covers an element or an overlay that enters the interface.
- `exit` covers an element or an overlay that leaves the interface.

Pair `easing.standard` with feedback and with entry. Pair `easing.exit` with a dismissal.
