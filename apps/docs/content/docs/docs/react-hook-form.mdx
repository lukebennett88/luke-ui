title: React Hook Form
description: Wire Luke UI fields to React Hook Form with Controller.

React Hook Form owns the form state, and Luke UI renders the controls.

## Initialise the form

Call `useForm` with `defaultValues` and a resolver, and keep the result as `form`. React Hook Form
takes the form's value types from the Zod schema, so no hand-written type repeats it.

```tsx
const schema = z.object({
	email: z.email('Enter a valid email address.'),
	name: z.string().min(1, 'Enter your name.'),
});

const form = useForm({
	defaultValues: { email: '', name: '' },
	resolver: zodResolver(schema),
});
```

## Integrate components

Wrap the fields in Luke UI's [`Form`](/components/forms/form). Set `validationBehavior="aria"` so
React Hook Form controls validation without browser submission blocking it. When every required
field should show a clear marker, set `necessityIndicator="required-label"`.

Wrap each control in `Controller`. Pass `field.value`, `field.onChange`, and `field.onBlur` to the
control, give `field.ref` to `inputRef`, and pass `field.name` as the HTML `name`. Set `isRequired`
on fields the schema requires. Schema validation does not set required control semantics on its own.

Pass `fieldState.error?.message` to `errorMessage`. A non-empty message marks the field invalid.

A checkbox or switch reads its value from `isSelected`.

<ExampleBlock src="forms/react-hook-form-checkbox" title="React Hook Form: Checkbox" />

`TextInputField`, `CheckboxField`, and `SwitchField` render a label, description, and error message
around the control, so `inputRef` is what reaches the input underneath. For `SelectField`, pass the
library's ref through `triggerRef` to reach the trigger button. A primitive that renders the control
itself, such as `ComboboxInput`, takes `field.ref` on `ref`.

Read [Validation](/docs/validation) for controlled errors versus native validation. Read
[Required fields](/docs/forms#required-fields) for necessity indicators.

## Focus the first invalid field

React Hook Form focuses the first invalid control after a failed submission, using the ref each
field registered. A field that never receives `field.ref` stays unfocused, and someone filling in
the form gets an error message without being taken to it.

Set `shouldFocusError: false` on `useForm` to turn this off.

## Submitting data

Pass `form.handleSubmit(onSubmit)` to Form's `onSubmit`. React Hook Form validates the fields before
calling your handler. Prefer `onSubmit` over Form's `action` for this integration, because the
library needs the submit event.
