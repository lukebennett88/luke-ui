Luke UI includes one icon set. All the icons have the same weight, and all use a 24 by 24 grid. The
Luke UI stylesheet draws them, so `Icon` needs no setup beyond the stylesheet import.

## Use an icon

Import `Icon` and give it a name from the set. The `name` prop accepts only the names in the gallery
above. The compiler rejects any other name. See [Icon](/components/visuals/icon) for the component
API.

## Size

Set `size` to `xsmall`, `small`, `medium`, or `large`. These sizes currently map to 16, 20, 24, and
32 CSS pixels at a 16px root. They use `rem` and scale with the root font size.

<ExampleBlock src="icon/sizes" title="Icon: Sizes" />

Controls size the icons inside them, so an icon in a control needs no `size`. A Button and an Icon
Button use `xsmall`. A field control uses `xsmall` at the `small` control size and `small` at
`medium`. An icon that has its own `size` keeps that size. Elsewhere, the default size is `medium`.

<ExampleBlock src="icon/container-size" layout="centered" title="Icon: Size from a control" />

## Colour

An icon takes the colour of the text around it, including the readable colour a Luke UI background
sets. To change the colour of an icon, wrap it in a [`Text`](/components/typography/text#colour)
with a `color`, as in this example.

<ExampleBlock src="icon/colours" title="Icon: Colour" />

An icon that gives information must have a contrast ratio of 3 to 1 or more against its background.
An icon that only decorates adjacent text has no contrast requirement.

## Accessibility

Each icon is decorative or informative.

The icon is decorative when the text next to it gives the meaning. Do not give it a title. The
component then hides the icon from assistive technology.

<ExampleBlock src="icon/decorative" layout="centered" title="Icon: Decorative" />

The icon is informative when it appears alone. Give it a `title`. The component then shows the icon
to assistive technology as an image.

<ExampleBlock src="icon/informative" layout="centered" title="Icon: Informative" />

Do not set `aria-hidden` and `title` on the same icon.

## When the set does not have an icon

Render your own `<svg>` and pass `iconRecipe()` as its `className`. The SVG then takes the same
sizes as `Icon`, including the size a control sets. See
[Icon](/components/visuals/icon#custom-icons).
