Use the Radio primitive when a layout needs custom placement for a radio group or its options. For
the standard labelled group, use [`RadioGroup`](/components/forms/radio-group).

<ExampleBlock src="radio-primitive/basic" title="Radio primitive: Basic" />

## Anatomy

`RadioGroupRoot` owns the selection, accessible group name, validation, form value, and size.
`RadioRoot` represents one option and takes its `value`. `RadioLabel` provides the clickable option
label. Place `RadioControl` inside it, with `RadioIndicator` inside the control.

Use `FieldLabel`, `FieldDescription`, and `FieldError` inside `RadioGroupRoot` when the group label,
description, or error needs a custom position. The group root connects those parts to the group.
Place a `FieldDescription` inside `RadioRoot` to describe one option. Each option still needs a
`RadioLabel`.
