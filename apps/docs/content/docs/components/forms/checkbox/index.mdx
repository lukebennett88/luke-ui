Use `Checkbox` when a person can choose an option independently of nearby controls. Pass
`description` to clarify what the option means.

## States

Use `defaultSelected` for an uncontrolled initial value, or pair `isSelected` with `onChange` when
application state owns the selection. `isIndeterminate` communicates a mixed state, such as a parent
option whose child options are only partly selected.

<ExampleBlock
	src="checkbox/states"
	title="Checkbox — States"
	description="Checked, unchecked, disabled, indeterminate, and invalid checkboxes."
/>

Disabled checkboxes cannot be changed or focused. Read-only checkboxes remain focusable so their
state is available to keyboard and assistive-technology users. Keyboard navigation shows a focus
ring. Pointer focus does not.

<ExampleBlock
	src="checkbox/controlled"
	title="Checkbox — Controlled"
	description="A controlled checkbox with explicit selection state."
/>

## Size

Use `size` to change the checkbox control without changing its label typography. `medium` is the
default. Use `small` in compact layouts and `large` where a larger control improves scanning.

<ExampleBlock
	src="checkbox/sizes"

/>

## Validation

Pass `errorMessage` with `isInvalid` when the choice blocks submission. Always pass both: an invalid
field with no message leaves someone who cannot see the border colour with no way to know what is
wrong.

<ExampleBlock
	src="checkbox/validation"
	title="Checkbox — Validation"
	description="A required checkbox with supporting text and a validation message."
/>

Read [Validation](/components/forms/validation) for how to word the message.

## Labels with Text

Wrap a checkbox in block `Text` when its label needs a specific text size. The control follows the
inherited line height, keeping its fixed visual square centred on the first line when the label
wraps. Outside `Text`, it uses the normal compact control size.

<ExampleBlock
	src="checkbox/first-line-alignment"
	title="Checkbox — First-line alignment"
	description="Checkbox controls follow the first line across Text sizes."

Use the [Checkbox primitive](/components/primitives/checkbox) to arrange the clickable content,
