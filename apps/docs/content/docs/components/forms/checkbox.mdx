Use `Checkbox` when someone can choose an option independently of nearby controls. Pass `label` to
name the option, and `description` to clarify what it means.

<ExampleBlock src="checkbox/basic" layout="centered" title="Checkbox: Basic" />

## Labels

Pass the visible label as `label`. The control renders first and the label second.

The label sits inside a native `<label>` element, so pass textual content only. Links and buttons
are not supported inside it. Place them next to the checkbox instead. To use content elsewhere on
the page as the label, omit `label` and pass its id to `aria-labelledby`. To supply the name
directly, omit `label` and pass `aria-label`. Pass `label` or exactly one of `aria-label` and
`aria-labelledby`.

```tsx
<Checkbox aria-label="Select row" />
```

## States

Use `defaultSelected` for an uncontrolled initial value, or pair `isSelected` with `onChange` when
application state owns the selection. `isIndeterminate` communicates a mixed state, such as a parent
option whose child options are only partly selected.

## Size

Use `size` to change the checkbox control. It does not change the label typography. `medium` is the
default. Use `small` in compact layouts and `large` where a larger control improves scanning.

<ExampleBlock src="checkbox/sizes" title="Checkbox: Size" />

## Validation

Set `isRequired` to require the choice. `Checkbox` shows its validation message after validation
fails. Pass `errorMessage` only for an error you already have, such as one from a form library or
your server. A non-empty message marks the checkbox invalid, and `Checkbox` has no `isInvalid` prop.
Read [Validation](/docs/validation) for where messages come from and how to write them.

The message hangs under the label text.

<ExampleBlock src="checkbox/validation" title="Checkbox: Validation" />

## Required marker

A required checkbox with a visible `label` shows a marker after the label text. The default
`necessityIndicator="icon"` adds an asterisk. `necessityIndicator="label"` appends “(required)”. A
checkbox named with `aria-label` or `aria-labelledby` shows no marker, because it has no visible
label.

## Labels with Text

Wrap a checkbox in block `Text` when its label needs a specific text size. The control follows the
inherited line height. It keeps its fixed visual square centred on the first line when the label
wraps. Outside `Text`, it uses the normal compact control size.

<ExampleBlock src="checkbox/first-line-alignment" title="Checkbox: First-line alignment" />

## IDs and refs

`id`, `className`, and `ref` target the checkbox's root element. Pass `inputId` to set the input's
id, and `inputRef` to reach the input.

## Form values

Pass `name` so the checkbox joins `FormData` when selected. Pass `value` to set the submitted value,
and `form` to associate a checkbox with a `<form>` it does not sit inside.

## Accessibility

Disabled checkboxes cannot receive focus, and their value cannot change. Read-only checkboxes remain
focusable, so someone who uses a keyboard or assistive technology can still perceive their state.
Keyboard navigation shows a focus ring. Pointer focus does not.

For custom anatomy, use the [Checkbox primitives](/components/primitives/checkbox).
