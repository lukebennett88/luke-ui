`Text` applies Luke UI typography without adding heading semantics. It needs a Luke UI theme root.
See [Getting started](/docs/installation).

<ExampleBlock src="text/basic" title="Text: Basic" />

Pass `slot` to fill a named text slot defined by a React Aria parent. Pass `slot={null}` to opt out
of surrounding slotted text context.

## Visually hidden

Set `isVisuallyHidden` to hide the text while keeping it available to assistive technology. Text
keeps its React Aria Text root. There is no extra wrapper. Use
[`VisuallyHidden`](/components/layout/visually-hidden) directly when the content is not typography
text, or when it must reveal on focus.

## Element type

`Text` renders React Aria's `Text` component, which uses a `span` by default. Set `elementType` to
choose a semantic element without changing the type treatment. `Text` trims Capsize space on known
block elements such as `p`, `div`, headings, and `blockquote`, and skips it for inline or unknown
element types.

```tsx
<Text elementType="p">A paragraph of supporting copy.</Text>

<Text elementType="label">Email address</Text>
```

## Typography

Pass `typography` to choose a style. `body` is the default. See [Typography](/docs/typography) for
the full style reference.

<ExampleBlock src="text/lead" title="Text: Lead typography" />

Set `fontWeight` only when you need to override the style's weight. Themes expose `body`, `label`,
`heading`, and `emphasis` roles for that purpose.

Use a larger style such as `display` or `heading1` for prominent content that is not a heading, such
as a large status value.

Use `fontVariantNumeric` to align numeric columns, format fractions and ordinals, or distinguish

## Trimming

Block text trims space above capitals and below the baseline by default. That makes vertical spacing
more predictable in cards and other bounded layouts. Inline text skips trim so its pseudo-elements
cannot interrupt the surrounding line. Set `shouldDisableTrim` explicitly when you need to override
the element-type inference.

<ExampleBlock src="text/trim" title="Text: Trimming" />

## Truncation

Use `lineClamp` to constrain text to one line or up to five lines. `Text` truncates overflow with an
ellipsis. It disables trimming automatically when you set `lineClamp`.

<ExampleBlock src="text/truncation" title="Text: Truncation" />

## Transform and decoration

Use `textTransform` and `textDecoration` when the content calls for them. These props affect the
rendered text only, so avoid using uppercase styling as a substitute for a clear label.

<ExampleBlock src="text/transform" title="Text: Transform and decoration" />

## Adornments

Pass `startContent` or `endContent` to place content before or after the text, such as an icon or a
`Kbd`. Each adornment is centred on the capitals of its first line. Compare compositions in
[First-line alignment](/docs/first-line-alignment).

Keep the default `span` inside a sentence or an underlined external link. Its inline flow preserves
the link's underline. Wrapped lines may return beneath `startContent`, and `endContent` follows the
final word. Use `p` for a standalone message. Use `div` for a navigation link, pager title, or
compound content. `elementType` selects the adornment layout and trim inference. Changing CSS
`display` alone selects neither.

<ExampleBlock src="text/adornments" title="Text: Adornments" />

With a block element type, wrapped lines align with the text, and `endContent` sits at the end of
the first line. An adornment taller than the line moves the text down to stay centred on it.

Set `gap` to a spacing token to change the space beside the adornments. It defaults to `sp4` for
inline text and `sp8` for block text. Responsive values require `initial` and follow the
[layout breakpoints](/docs/layout#responsive-values).

Adornments take phrasing content and are part of the element. Their text joins its accessible name.
Place an action beside a heading rather than inside its adornments.

## Compound content

Use `elementType="div"` with a `Stack` for a title and description. The adornments follow the outer
Text's typography, the same as for a single run of text, so the first line of the content must use
that typography. A nested Text in the default `body` style aligns with a `body` outer Text, whatever
its `fontWeight`.

<ExampleBlock src="text/compound" title="Text: Compound content" />

When the first line needs another style, set `typography` on the outer Text and set
`shouldInheritFont` on the nested Text that renders that line. In development, Text logs an error
when the first line's font differs from the outer Text's.

<ExampleBlock src="text/compound-typography" title="Text: Compound content typography" />

Set `lineClamp` on each text run that needs truncation. A compound wrapper does not clamp its nested
blocks as one text run. Use [Box](/components/layout/box) or [Cluster](/components/layout/cluster)
when alignment should follow the whole content box or the items should wrap.
