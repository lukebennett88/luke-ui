---
title: Kbd
description: Represents keyboard input or a hotkey.
---

`Kbd` marks keyboard input, such as a shortcut or a key name. It renders a native `kbd` element, which conveys keyboard-input semantics to assistive technology, and uses the theme's fixed code font.
