`Blockquote` quotes another source as a block. It renders a native `blockquote` element, which
conveys quotation semantics to assistive technology.

<ExampleBlock src="blockquote/basic" title="Blockquote — Basic" />

## Typography

`Blockquote` accepts the `size`, `fontWeight`, and `lineClamp` props from
[Text](/components/typography/text).
