---
title: Blockquote
description: Block-level quotation from another source.
---

`Blockquote` quotes another source as a block. It renders a native `blockquote` element, which
conveys quotation semantics to assistive technology.

<ExampleBlock
	src="blockquote/basic"
	title="Blockquote — Basic"
	description="A simple block-level quotation."
/>

## Typography

`Blockquote` accepts the `size`, `fontWeight`, and `lineClamp` props from
[Text](/components/typography/text).

<ExampleBlock
	src="blockquote/size"
	title="Blockquote — Size"
	description="Compare the coordinated 100–900 size steps."
/>

<ExampleBlock
	src="blockquote/font-weight"
	title="Blockquote — Font weight"
	description="Compare the body, emphasis, heading, and label weight roles."
/>

<ExampleBlock
	src="blockquote/line-clamp"
	title="Blockquote — Line clamp"
	description="Compare one-line and two-line truncation."
/>
