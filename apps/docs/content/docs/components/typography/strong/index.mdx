---
title: Strong
description: Marks text to signify strong importance.
---

`Strong` marks text as important. It renders a native `strong` element, which conveys importance to assistive technology, and uses the theme's emphasis font weight.

<ExampleBlock
	src="strong/basic"
	title="Strong — Basic"
	description="Strong markers within a paragraph."
/>

`Strong` stays inline and inherits the surrounding typography. Use `textWrap` to control wrapping or `lineClamp` to constrain longer text.

Use `<Text fontWeight="emphasis">` when text only needs to look bold. `Strong` tells assistive technology the text matters.
