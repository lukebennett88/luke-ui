`Prose` styles rendered Markdown, MDX, or CMS content. It spaces the blocks and styles lists, code
blocks, tables, rules, and media. It does not set a content width or style headings and paragraphs,
so map those elements to [Heading](/components/typography/heading) and
[Text](/components/typography/text).

## Lists

Lists get markers and indentation at every nesting level. Untyped ordered lists use decimal markers.
A typed list, such as `<ol type="a">`, keeps its HTML markers, except in Chromium under a reset that
removes list markers, such as Tailwind Preflight.

## Wide content

Images and videos shrink to fit the content width. A long line in a code block scrolls inside the
`pre`. Set `tabIndex={0}` on the `pre` so someone using a keyboard can scroll it.

A table grows past the content width when its columns need more room. Wrap it in
[Scroll Fade](/components/layout/scroll-fade), which scrolls it in place and makes it a focusable,
named region while it overflows. `Prose` spacing does not reach the wrapper, so set
`marginBlockStart="sp40"` on it to match the gap before a table.

<ExampleBlock src="prose/wide-content" title="Prose: Wide content" />

## Opting out

Add the `not-prose` class to an element to keep `Prose` styles off it and everything inside it. Use
it for an interactive widget or a component that sets its own layout. A `Prose` nested inside that
element applies again.

```tsx
<Prose>
	<p>Spaced like the rest of the content.</p>
	<div className="not-prose">
		<p>No Prose margins here.</p>
	</div>
</Prose>
```

The element still keeps the gap that `Prose` puts after a heading or rule.

## Browser support

`Prose` uses CSS `@scope`, which needs Chrome 118, Safari 17.4, or Firefox 146. Older browsers show
the content without `Prose` styles.
