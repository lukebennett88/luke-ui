`Prose` applies fixed vertical rhythm and document list structure to rendered Markdown, MDX, or
content management system output. It sets no typography, colour, weight, type scale, or width, and
adds no space outside itself.

<ExampleBlock src="prose/basic" title="Prose — Basic" />

## Best practices

| Practice                               | Why                                                                |
| -------------------------------------- | ------------------------------------------------------------------ |
| Wrap a whole document.                 | One element has no rhythm to manage.                               |
| Keep interface layout outside `Prose`. | Cards, forms, and toolbars own their own spacing.                  |
| Constrain the measure on an ancestor.  | `Prose` sets no width, so the surrounding layout owns line length. |

## Lists

The Luke UI reset strips markers and indent from lists because interface lists are often menus.
`Prose` restores them for documents, including nested markers. An `ol` keeps a valid `type`
attribute such as `<ol type="a">`.

<ExampleBlock src="prose/lists" title="Prose — Lists" />

## Overriding the rhythm

Every rule has zero specificity, so a plain class on an element inside `Prose` can adjust one block
without `!important` or a longer selector.

```tsx
<Prose>
	<figure className={styles.fullBleedFigure}>
		<img alt="" src="/diagram.png" />
	</figure>
</Prose>
```
