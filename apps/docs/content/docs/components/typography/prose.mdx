`Prose` adds vertical rhythm and list styling to long-form content. Pair it with
[Heading](/components/typography/heading) and [Text](/components/typography/text) for visual
hierarchy, or map rendered Markdown and CMS elements to those components.

Use [ProsePre](/components/typography/prose#wide-code-blocks) for block code that may overflow
horizontally.

<ExampleBlock src="prose/basic" title="Prose — Basic" />

## Lists

Lists inside `Prose` include markers and indentation, including nested lists.

<ExampleBlock src="prose/lists" title="Prose — Lists" />

## Wide code blocks

`ProsePre` wraps a `<pre>` in a keyboard-focusable scroll region with a required accessible name.
Use it for block code that may overflow horizontally, including when mapping Markdown or CMS
`<pre><code>` output.

<ExampleBlock src="prose/wide-code" title="Prose — Wide code" />

## Custom spacing

Add a class to an element inside `Prose` to override its spacing.

```tsx
<Prose>
	<figure className={styles.tightFigure}>
		<img alt="" src="/diagram.png" />
	</figure>
</Prose>
```

```css
.tightFigure {
	margin-block-start: var(--luke-space-sp16);
}
```

## Related components

[Heading](/components/typography/heading) and [Text](/components/typography/text) own typography and
visual hierarchy. Use them inside `Prose` when you need styled headings and body text.
