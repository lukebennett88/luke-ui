`Prose` applies a fixed document rhythm to rendered Markdown, MDX, or content management system
output. It restores document list structure and owns vertical spacing between blocks. It does not
apply typography, text colour, weight, type scale, or width. Raw headings and paragraphs keep their
default text styles unless you wrap them in components such as
[Heading](/components/typography/heading) or [Text](/components/typography/text). Constrain the
measure on a surrounding layout. `Prose` adds no space outside itself.

## Lists

The Luke UI reset strips markers and indent from lists because interface lists are often menus.
`Prose` restores them for documents, including nested lists.

<ExampleBlock src="prose/lists" title="Prose — Lists" />

## Overriding the rhythm

Every rule has zero specificity, so a plain class on an element inside `Prose` can adjust one block
without `!important` or a longer selector.

```tsx
<Prose>
	<figure className={styles.fullBleedFigure}>
		<img alt="" src="/diagram.png" />
	</figure>
</Prose>
```
