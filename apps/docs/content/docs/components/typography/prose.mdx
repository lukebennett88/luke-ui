`Prose` adds vertical rhythm and list styling to long-form content. It does not constrain content
width. Pair it with [Heading](/components/typography/heading) and
[Text](/components/typography/text) for visual hierarchy, or map rendered Markdown and CMS elements
to those components.

<ExampleBlock src="prose/basic" title="Prose: Basic" />

## Lists

Lists inside `Prose` include markers and indentation, including nested lists. Untyped ordered lists
use decimal markers, and typed lists keep their HTML `type` markers. Under a reset that removes list
markers, such as Tailwind Preflight, Chromium shows no letter or roman markers. Decimal markers stay
in every browser.

<ExampleBlock src="prose/lists" title="Prose: Lists" />

## Media

Images and videos shrink to fit the content width without changing their proportions.

<ExampleBlock src="prose/media" title="Prose: Media" />

## Code blocks

Use native `<pre><code>` for code blocks and [Code](/components/typography/code) for inline
fragments. Long code lines scroll inside `pre`. Add `tabIndex={0}` to an overflowing `pre` so it can
receive keyboard focus.

<ExampleBlock src="prose/code" title="Prose: Code blocks" />

## Tables

Tables fill the available width but can overflow when their content is too wide. Wrap wide tables in
[ScrollFade](/components/layout/scroll-fade) with an accessible name.

The scroll wrapper needs its own spacing. After a paragraph, set `marginBlockStart="sp40"` on the
wrapper to match the usual `Prose` gap.

<ExampleBlock src="prose/wide-table" title="Prose: Wide table" />

## Opting out

Add the `not-prose` class to an element to keep `Prose` spacing, list styles, and table padding off
it and everything inside it. Use it for an interactive widget or a component that sets its own
layout. A `Prose` inside that element applies again.

```tsx
<Prose>
	<p>Spaced like the rest of the content.</p>
	<div className="not-prose">
		<p>No Prose margins here.</p>
	</div>
</Prose>
```

A `not-prose` element that follows a heading or rule keeps the gap `Prose` puts after it.

`Prose` styles use CSS `@scope`, which needs Chrome 118, Safari 17.4, or Firefox 146. Older browsers
show the content without `Prose` spacing.
