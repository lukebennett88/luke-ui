`Prose` adds vertical rhythm and list styling to long-form content. Use it with Luke UI typography
components, or map rendered Markdown and CMS elements to those components.

<ExampleBlock src="prose/basic" title="Prose — Basic" />

## Lists

Lists inside `Prose` include markers and indentation, including nested lists.

<ExampleBlock src="prose/lists" title="Prose — Lists" />

## Custom spacing

Add a class to an element inside `Prose` to override its spacing.

```tsx
<Prose>
	<figure className={styles.tightFigure}>
		<img alt="" src="/diagram.png" />
	</figure>
</Prose>
```

```css
.tightFigure {
	margin-block-start: var(--luke-space-sp16);
}
```
