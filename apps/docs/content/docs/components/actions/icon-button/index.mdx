---
title: Icon Button
description: A compact icon-only control for an action.
---

`IconButton` triggers a familiar compact action, such as closing a panel, deleting a row, or adding
an item. Give every icon button an accessible name because it has no visible label.

/>

## Size

`medium` is the default. Use `small` for compact toolbars and dense row actions. Keep controls in a
group at the same size.

<ExampleBlock
	src="icon-button/size"
	title="Icon Button — Size"
	description="Small and medium icon buttons for compact and default layouts."
/>

## Appearance

`IconButton` uses the same `appearance` options as [`Button`](/components/actions/button). `solid`
is the default. Choose `subtle` or `ghost` when a secondary control needs less emphasis.

<ExampleBlock
	src="icon-button/appearance"
	title="Icon Button — Appearance"
	description="Choose an appearance that matches the control's emphasis."
/>

## Tone

Use `tone` to communicate intent. `neutral` is the default, `accent` identifies a primary action,
and `danger` marks a destructive one.

<ExampleBlock
	src="icon-button/tones"

/>

## Pending

Set `isPending` while an action is running. The control remains focusable, ignores further presses,
and replaces its icon with a busy cue.

<ExampleBlock
	src="icon-button/pending"
	title="Icon Button — Pending"
	description="Pending icon buttons ignore repeat presses while the action runs."
/>

## Disabled

Set `isDisabled` when the action is unavailable. Disabled controls cannot receive focus or be
pressed.

<ExampleBlock
	src="icon-button/disabled"
	title="Icon Button — Disabled"
	description="Disabled icon buttons are visible but unavailable."
/>

## Accessibility

Provide `aria-label` or `aria-labelledby` for every icon button. Name the action, not the icon. Use
a labelled [`Button`](/components/actions/button) when the icon is unfamiliar or visible text would
make the action clearer.
