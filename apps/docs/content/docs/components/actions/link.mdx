`Link` navigates to another URL or route. Use [`Button`](/components/actions/button) for an action
such as saving, submitting, or opening a dialog.

<ExampleBlock src="link/basic" title="Link: Basic" />

## Appearance

`text` is the default. Text Links use the theme's label weight, `500` by default, to stand out from
the surrounding text. Use them only inline within text that has a lighter weight, such as body text.
Set `appearance="button"` when the destination needs a button-shaped call to action. A button-shaped
Link remains a link and keeps its native navigation behaviour.

<ExampleBlock src="link/appearance" title="Link: Appearance" />

## Prominence

`standard` is the default. Choose `low` for a secondary destination and `high` for a primary
destination. Text Links use the accent text colour at every prominence, so prominence changes the
underline and not the hue. Hover and press toggle the underline. Low text Links have no underline at
rest and gain one, and standard and high text Links are underlined at rest and lose it. Keyboard
focus shows the focus ring, and low text Links also underline. Press also shifts the text colour. On
a solid background, every prominence takes the background's readable text colour.

## Disabled

Set `isDisabled` only when a destination is temporarily unavailable. Disabled links cannot receive
focus or respond to activation. Explain why nearby when someone needs that information.

<ExampleBlock src="link/disabled" title="Link: Disabled" />

## Accessibility

Write link text that names the destination and makes sense outside its surrounding sentence. Avoid
generic labels such as “Click here”.
