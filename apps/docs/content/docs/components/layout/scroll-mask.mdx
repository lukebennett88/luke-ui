`ScrollMask` keeps content scrollable without showing the native scrollbar. Browsers without CSS
scroll-driven animations show no fade and keep the native scrollbar. Read
[Layout](/docs/layout#choose-a-layout-component) to choose a layout component.

<ExampleBlock src="scroll-mask/basic" title="Scroll Mask — Basic" />

## Block axis

Pass `axis="block"` to scroll on the block axis. The default `axis="inline"` scrolls on the inline
axis. Both values follow the element's writing mode.

<ExampleBlock src="scroll-mask/block-axis" title="Scroll Mask — Block axis" />

## Semantic structure

ScrollMask always renders a `div`. Compose semantic elements around or inside the scrollport instead
of changing its root.

<ExampleBlock src="scroll-mask/compose-semantics" title="Scroll Mask — Navigation" />

## Accessibility

Pass `aria-label` or `aria-labelledby`. The label must describe the scrollable content.

When content overflows, the scrollport becomes a focusable, named region with a focus ring. This
also applies when its content contains links or buttons.

When the content fits, ScrollMask removes the mask, the tab stop, the region role, and the name.
