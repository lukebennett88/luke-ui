Use `ScrollMask` when scrollable content should use edge fades instead of a visible native
scrollbar. When edge fades are unavailable, the native scrollbar remains visible. Read
[Layout](/docs/layout#choose-a-layout-component) to choose a layout component.

<ExampleBlock src="scroll-mask/basic" title="Scroll Mask — Basic" />

## Block axis

Pass `axis="block"` to scroll on the block axis. The default `axis="inline"` scrolls on the inline
axis. Both values follow the element's writing mode.

<ExampleBlock src="scroll-mask/block-axis" title="Scroll Mask — Block axis" />

## Accessibility

Pass exactly one of `aria-label` or `aria-labelledby`.

When content overflows, ScrollMask becomes a focusable, named region with a focus-visible treatment.

When the content fits, ScrollMask has no region role, accessible-name attribute, or extra tab stop.

ScrollMask always renders a `div`. Compose semantic structure around or inside it.
