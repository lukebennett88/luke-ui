`ScrollMask` is a scroll container that fades the logical start and end edges when more content is
available to scroll. The scrollport becomes a keyboard tab stop only while it overflows. Read
[Layout](/docs/layout#choose-a-layout-component) to choose a layout component.

<ExampleBlock src="scroll-mask/basic" title="Scroll Mask — Basic" />

## Block axis

Pass `axis="block"` to scroll on the block axis. The default `axis="inline"` scrolls on the inline
axis. Both values follow the element's writing mode.

<ExampleBlock src="scroll-mask/block-axis" title="Scroll Mask — Block axis" />

## Compose semantics outside

ScrollMask always renders a `div` scrollport. Put landmark or list semantics on a parent when you
need them.

<ExampleBlock src="scroll-mask/compose-semantics" title="Scroll Mask — Navigation" />

## Accessibility

When content overflows, ScrollMask makes the scrollport focusable and applies Luke UI's standard
`:focus-visible` ring. The `div` also becomes a named region, so pass `aria-label` or
`aria-labelledby`. That name is applied only while the automatic region role is active.

When content fits, ScrollMask removes the mask, the extra tab stop, and the automatic region naming
attributes.
