`Box` accepts Luke UI layout properties and renders a `div` by default. It places content in a
layout, adds token spacing, constrains an element's size, or controls a flex or grid child. Use a
normal `div` when no supported layout property applies.

<ExampleBlock src="box/basic" title="Box — Basic" />

## Layout properties

Box supports display, logical margin and padding, inline and block sizing, positioning, overflow,
gap, flex, and grid-child properties. It does not set grid container properties. Keep grid-template
rules in the application CSS or a component that owns that layout.

Use logical properties such as `paddingInline`, `marginBlockStart`, and `maxInlineSize`. They adapt
to the writing direction without left and right variants.

```tsx
<Box display="flex" alignItems="center" gap="300" maxInlineSize="42rem" paddingInline="600">
	{children}
</Box>
```

## Responsive values

Pass a direct value when it does not change. Use an object keyed by breakpoint when it does. Values
cascade upward from `initial`, so only specify the changes.

<ExampleBlock src="box/responsive-layout" title="Box — Responsive layout" />

```tsx
<Box
	display="flex"
	flexDirection={{ initial: 'column', medium: 'row' }}
	gap={{ initial: '200', medium: '600' }}
>
	{children}
</Box>
```

See [Layout](/layout) for the available keys and fixed thresholds.

## Spacing values

Padding, gap, and margin accept `0` and the semantic steps `100`, `200`, `300`, `400`, `600`, `800`,
`1000`, `1200`, and `1600`. Margin also accepts `auto`. Sizing, inset, flex-basis, order, and
grid-placement properties accept their CSS values.

## Choose the rendered element

Set `elementType` to render an element other than `div`, such as an `a`. Box's DOM props then match
that element, so `href` and other element-specific attributes type-check.

`elementType` accepts a curated set of layout and sectioning elements: `a`, `article`, `aside`,
`div`, `footer`, `header`, `li`, `main`, `nav`, `ol`, `section`, `span`, and `ul`. Elements that
carry their own behaviour, such as `input` or `button`, are not included. Use a dedicated component
or the `render` prop for those cases.

Use `Link` from `@luke-ui/react/link` for link styling, tone, and a standalone target.
`elementType="a"` suits a layout region that needs to be a link, such as a card.

<ExampleBlock src="box/anchor-element" title="Box — Anchor element" />

```tsx
<Box elementType="a" href="#account-summary" padding="400">
	Account summary
</Box>
```

## Render a custom div

Use `render` for a compatible custom `div`, such as a motion wrapper. Spread the supplied props on
the final element. It then receives Box's class name, inline style, ref, accessibility attributes,
and event handlers. `render` keeps the rendered element a `div`. Use `elementType` to change the
element instead.

```tsx
<Box padding="400" render={(props) => <MotionDiv {...props} />}>
	Account summary
</Box>
```

## Visual styles

Box only covers layout. Use a component API for visual states and typography. When a custom element
needs a colour, radius, or depth value, use the public variables from `@luke-ui/react/theme`.

```tsx
import { vars } from '@luke-ui/react/theme';

<Box
	padding="600"
	style={{ backgroundColor: vars.color.surface.recessed, borderRadius: vars.radius.surface }}
>
	Account summary
</Box>;
```
