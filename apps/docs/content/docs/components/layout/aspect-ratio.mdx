`AspectRatio` establishes a preferred inline-to-block ratio. Content may increase the block size. It
does not crop, fit, clip, or size its children. Size media such as an `iframe`, `img`, or `video`
yourself when it should fill the frame. Read [Layout](/docs/layout#choose-a-layout-component) to
choose a layout component.
