`AspectRatio` locks a frame to an inline-to-block ratio and sizes its direct child to fill that
frame. Use it for media such as an `iframe`, `img`, or `video`. The media element needs no size of
its own. Read [Layout](/docs/layout#choose-a-layout-component) to choose a layout component.
