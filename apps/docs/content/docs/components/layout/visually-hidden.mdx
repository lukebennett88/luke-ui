Use `VisuallyHidden` for text labels behind icon-only controls, extra context for links, or status
messages in live regions. The content stays available to assistive technology and can be referenced
by `aria-labelledby` or `aria-describedby`.

<ExampleBlock src="visually-hidden/basic" title="Visually Hidden: Basic" />

## Render a different element

By default `VisuallyHidden` renders a `span`. Pass `elementType` to render a different element, such
as a semantic heading, `label`, or list item. `VisuallyHidden` keeps the hidden styles on that
element.

```tsx
<VisuallyHidden elementType="h2">Search results</VisuallyHidden>
```

## Show content on focus

Set `isFocusable` for content such as a skip link. The content becomes visible when it or a
descendant receives focus, then hides again when focus leaves. Put the focusable control inside
`VisuallyHidden`.
