Use `VisuallyHidden` for text labels behind icon-only controls, extra context for links, or status
messages in live regions. The content stays available to assistive technology and can be referenced
by `aria-labelledby` or `aria-describedby`.

<ExampleBlock src="visually-hidden/basic" title="Visually Hidden: Basic" />

## Render a different element

Pass `elementType` to render a semantic element, such as a heading. The default is `span`.

```tsx
<VisuallyHidden elementType="h2">Search results</VisuallyHidden>
```
