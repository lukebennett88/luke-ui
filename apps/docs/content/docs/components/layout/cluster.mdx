`Cluster` lays out direct children on the logical inline axis. Read
[Layout](/docs/layout#choose-a-layout-component) to choose a layout component.

<ExampleBlock src="cluster/basic" title="Cluster: Basic" />

## Alignment

`justifyContent` defaults to `flex-start`. `alignItems` defaults to `center`.

<ExampleBlock src="cluster/alignment" title="Cluster: Alignment" />

## Wrapping

`flexWrap` defaults to `wrap`. Set `nowrap` when children should stay on one line, or `wrap-reverse`
to reverse wrap direction. Responsive objects use the same breakpoint keys as other layout props.

<ExampleBlock src="cluster/flex-wrap" title="Cluster: No wrap" />

## Choose the rendered element

Cluster uses
[Box's `elementType` and `render` contract](/components/layout/box#choose-the-rendered-element).
