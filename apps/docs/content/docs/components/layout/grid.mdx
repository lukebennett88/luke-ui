`Grid` lays out direct children in two dimensions. Use it when a layout needs explicit columns,
rows, or named areas. Use [Stack](/components/layout/stack) or [Cluster](/components/layout/cluster)
when children flow on one axis. Read [Layout](/docs/layout#choose-a-layout-component) to choose a
layout component.

Pass a number to `columns` for that many equal columns. Each column can shrink below the width of
its content, so long content wraps instead of widening one column.

<ExampleBlock src="grid/basic" title="Grid: Basic" />

Without `columns` or `areas`, Grid has one column that grows with its content. Pass `columns={1}`
when long content should wrap inside the grid instead of widening it.

## Columns from the available space

Pass a CSS `repeat(auto-fit, …)` value when the column count should follow the available width. Wrap
the minimum column size in `min(…, 100%)` so a parent narrower than the minimum does not overflow.

<ExampleBlock src="grid/auto-fit" title="Grid: Auto-fit columns" />

## Tracks and named areas

`columns` and `rows` also accept a CSS value such as `"1fr 1fr"`. `areas` takes one string per row.
Name each cell, use `.` for an empty cell, and place a child in an area with the `area` prop of
[`GridItem`](#place-a-child).

Without `columns`, columns from `areas` size to their content. Each named area must form one filled
rectangle.

<ExampleBlock src="grid/structural" title="Grid: Tracks and named areas" />

## Responsive layouts

`columns`, `rows`, and `areas` accept a responsive object with a required `initial` value. Each
`columns` breakpoint can be a number or a CSS value. Stack named areas in one column at `initial`,
then arrange them from a wider breakpoint.

<ExampleBlock src="grid/responsive" title="Grid: Responsive areas" />

## Place a child

`GridItem` places one child in its parent Grid and does nothing else. It renders a `div` and accepts
`area`, `column`, `row`, and the root props `children`, `className`, `style`, `ref`, `elementType`,
and `renderRoot`. It does not accept Box layout or appearance props. Style the item through
[`renderRoot`](#style-a-child).

`area` takes the name of an area from the parent's `areas`. The value is a plain string, so a name
the parent does not define compiles and places nothing. The type does not check it against `areas`.

`column` and `row` take a line placement: `auto`, a line number such as `"2"`, a span such as
`"span 2"`, a start and end such as `"2 / 4"`, or a start and a span such as `"1 / span 2"`.
Negative lines count from the end, so `"1 / -1"` covers every explicit column. The types use
`${number}`, which accepts any numeric string. It does not check for an integer or a valid track.
Pass named lines and other complex placements through `className`.

All three props accept a responsive object.

## Spanning columns

Use `column="span 2"` when an item should cover more than one column.

When `columns` is a number, keep each span within the active column count at every breakpoint. A
span that fits at `bp768` can overflow a smaller `initial` column count, so change both values
together.

<ExampleBlock src="grid/spanning" title="Grid: Spanning columns" />

## Explicit lines

Place an item between grid lines with `column` and `row`. Items without a placement fill the
remaining cells in order.

## Style a child

`GridItem` has no styling props. Pass `renderRoot` to render a [Box](/components/layout/box) or
another layout component as the item. The callback receives the resolved `children`, `className`,
`style`, and `ref`. Spread them onto the element you return, and the grid item is that element, with
no extra wrapper. Put DOM attributes on the returned element.

<ExampleBlock src="grid/styled-item" title="Grid: Style an item" />

Read [Box](/components/layout/box#own-the-rendered-element) for the `renderRoot` contract.
`elementType` and `renderRoot` are mutually exclusive.

## Nest a layout

Return a `Stack`, a `Grid`, or any other layout component from `renderRoot` to lay out the contents
of a grid item. The returned component is the item, so it takes part in the parent grid and lays out
its own children.

<ExampleBlock src="grid/nested-layout" title="Grid: Nested layouts" />

## Migrate from Box placement props

`Box` and the other layout components no longer accept `gridArea`, `gridColumn`, `gridColumnStart`,
`gridColumnEnd`, `gridRow`, `gridRowStart`, or `gridRowEnd`. Wrap the element in `GridItem`, and
render the Box through `renderRoot` to keep its other props.

| Removed prop                                  | Replacement                                    |
| --------------------------------------------- | ---------------------------------------------- |
| `gridArea="main"`                             | `area="main"`                                  |
| `gridColumn="span 2"`                         | `column="span 2"`                              |
| `gridColumnStart="2"` and `gridColumnEnd="4"` | `column="2 / 4"`                               |
| `gridRow="span 2"`                            | `row="span 2"`                                 |
| `gridRowStart="2"` and `gridRowEnd="4"`       | `row="2 / 4"`                                  |
| A named line or another complex expression    | A `className` that sets the CSS `grid-*` value |

```tsx
// Before
<Box gridColumn="span 2" padding="space.16">
	<Text>First</Text>
</Box>

// After
<GridItem column="span 2" renderRoot={(props) => <Box {...props} padding="space.16" />}>
	<Text>First</Text>
</GridItem>
```

To place a layout component, such as a `Stack` with `gridColumn="span 2"`, pass it to `renderRoot`
in the same way. See [Nest a layout](#nest-a-layout).

## Alignment

`alignItems` and `justifyItems` place each child within its grid area. `alignContent` and
`justifyContent` distribute the tracks when the grid is larger than its tracks.

## Accessibility

Grid placement changes visual position only. Reading order and focus order follow the DOM order.
This applies to `area`, `column`, `row`, and `order`. Arrange areas and placements so the visual
order matches the DOM order at every breakpoint.
