`Track` places an optional fixed rail on each side of a flexible centre, on the inline axis. Read
[Layout](/docs/layout) to choose a layout component.

<ExampleBlock src="track/basic" title="Track — Basic" />

## Rails

`railStart` and `railEnd` are both optional and never shrink below their content. An omitted rail
renders no wrapper, so it contributes no gap.

<ExampleBlock src="track/rails" title="Track — Rails" />

## Alignment

`railAlignment` sets the cross-axis alignment of the rails against Track's block box. `start` is the
default.

<ExampleBlock src="track/alignment" title="Track — Alignment" />

## Align rails to the first line

`firstLine` centres each rail against a box fixed at exactly one line height, so a rail stays level
with the centre's first line even when the centre wraps.

That line height resolves against what Track itself inherits, not the actual rendered line height of
the centre's children. Give Track a centre whose inherited line-height metrics match its own, or the
rail sits against the wrong line. A `Heading`, or `Text` at a different size, does not move where
the rail sits.

<ExampleBlock src="track/first-line" title="Track — Align rails to the first line" />

## Long and wrapping content

The centre grows to fill available space and shrinks below its own content size, so a long unbroken
string never forces Track to overflow. Ordinary wrapping text behaves the same way inside a narrower
container.

<ExampleBlock src="track/wrapping" title="Track — Long and wrapping content" />

## Choose the rendered element

`div` is the default `elementType`. Set `elementType="li"` to render Track as a direct child of `ul`
or `ol`.

<ExampleBlock src="track/element" title="Track — Choose the rendered element" />

Set `elementType="span"` to keep Track inside phrasing content. Track's internal rail and centre
wrappers also render as `span`, and the root becomes an inline-level box so Track flows inside a
sentence instead of breaking onto its own line. You remain responsible for passing children that are
themselves valid phrasing content.

<ExampleBlock src="track/element-span" title="Track — Inside phrasing content" />
