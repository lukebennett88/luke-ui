`Track` places an optional fixed rail on each side of a flexible centre, on the inline axis. Read
[Layout](/docs/layout) to choose a layout component.

<ExampleBlock src="track/basic" title="Track — Basic" />

Pass `railStart`, `railEnd`, or both to place fixed content around the flexible centre. Leave both
props unset when the centre needs no rails.

## Alignment

`railAlignment` sets how the rails line up with a centre that spans more than one line. Use `center`
for a compact status or icon beside a message. Use `firstLine` for a taller trailing action beside a
wrapped task title.

`start` and `end` are uncommon choices. Use `start` for a marker or avatar that must align with the
top of the centre, or `end` for metadata that must align with its bottom edge.

`firstLine` uses Track's inherited line height. If the centre contains a `Heading` or `Text` with a
different line height, the rail still aligns to Track's line height.

<ExampleBlock src="track/alignment" title="Track — Alignment" />

## Long and wrapping content

The centre shrinks beside fixed rails, so ordinary text can wrap within the available width. Choose
truncation on the centre content when a long value must stay on one line.

<ExampleBlock src="track/wrapping" title="Track — Long and wrapping content" />

## Choose the rendered element

`div` is the default `elementType`. Set `elementType="li"` to render Track as a direct child of `ul`
or `ol`.

<ExampleBlock src="track/element" title="Track — Choose the rendered element" />

Set `elementType="span"` to keep Track inside phrasing content. Track's internal rail and centre
content must also be valid phrasing content.

<ExampleBlock src="track/element-span" title="Track — Inside phrasing content" />
