`Box` accepts Luke UI layout properties and renders a `div` by default. It places content in a
layout, adds token spacing, constrains an element's size, or controls a flex or grid child. Use a
normal `div` when no supported layout property applies.

<ExampleBlock src="box/basic" title="Box: Basic" />

## Layout properties

Box supports display, logical margin and padding, inline and block sizing, positioning, overflow,
gap, flex, and grid-child properties. It does not set grid tracks or areas. Use
[Grid](/components/layout/grid) for a grid container.

```tsx
<Box display="flex" alignItems="center" gap="sp12" maxInlineSize="42rem" paddingInline="sp24">
	{children}
</Box>
```

## Responsive values

Pass a direct value when it does not change. Use an object keyed by breakpoint when it does. Read
[Layout](/docs/layout#responsive-values) for the breakpoint list, the cascade from `initial`, and a
worked example.

## Spacing values

Padding, gap, and margin accept value-based spacing keys. Read
[Layout](/docs/layout#spacing-and-sizing) for the full scale and for logical property names.

## Choose the rendered element

Set `elementType` when the layout needs a supported structural element. The prop does not change
Box's accepted DOM props. Box owns the element and its DOM attributes.

The supported elements are `article`, `aside`, `dd`, `div`, `dl`, `dt`, `figcaption`, `figure`,
`footer`, `header`, `li`, `main`, `nav`, `ol`, `section`, `span`, and `ul`.

## Own the rendered element

Use `renderRoot` when the callback must own the element and its DOM attributes. The callback
receives `domProps` containing resolved `children`, `className`, `style`, and a callback `ref` as
its first argument. Its second argument is an empty state object. Put other DOM attributes on the
element the callback returns. You may omit or replace supplied props. You then own the consequences.

Do not combine `renderRoot` with `elementType`. Use `Link` or `Button` when you need their
behaviour.

<ExampleBlock src="box/render-element" title="Box: Own the rendered element" />

Read [Composition](/docs/composition#render-a-different-dom-component) for the general `elementType`
and `renderRoot` rule.

## Visual styles

Box accepts theme-backed background, border colour, radius, and depth values, plus fixed border
width and style values. Each value is a public token, so the options match the
[token reference](/docs/token-reference). Use a component API for interaction states and typography.

`borderColor="control"` is a guaranteed control boundary that reaches 3:1 against the base, field,
and overlay surfaces. The role colours, such as `borderColor="warning"`, are decorative tints. Do
not rely on one alone to show a required state. `borderColor="decorative"` is a separator. When a
custom element that is not a Box needs a colour, radius, or depth value, use `vars` from
`@luke-ui/react/theme`. Read [Styling](/docs/styling#use-semantic-variables-for-custom-ui) for when
to reach for `vars`, and the [token reference](/docs/token-reference) for the contract.
