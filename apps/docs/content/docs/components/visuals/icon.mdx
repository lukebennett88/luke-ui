`Icon` shows an icon from the Luke UI set. It takes the colour of the text around it.

See [Iconography](/docs/iconography) for available icons, sizing, colour, and setup.

<ExampleBlock src="icon/basic" layout="centered" title="Icon: Basic" />

## Custom icons

For an icon that is not in the set, such as a brand mark, render an ordinary `<svg>`. Pass
`iconRecipe()` as its `className` to give it the sizes `Icon` uses. Paint it with `currentColor` to
follow the text colour. Hide a decorative SVG with `aria-hidden`. Name an informative one with
`role="img"` and `aria-label`.

<ExampleBlock src="icon/custom" layout="centered" title="Icon: Custom" />

## Accessibility

Pass `title` when an icon conveys meaning without adjacent text, such as a standalone status icon.
`Icon` then exposes it to assistive technology with `role="img"`. When `title` is omitted, the icon
is decorative.

Read [Iconography](/docs/iconography#accessibility) for decorative and informative examples.
