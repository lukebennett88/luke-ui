`LoadingSpinner` shows that work is in progress. Use it on its own for a small loading region, or
wrap final content to replace it in place.

## Size

`medium` is the default. Set `size` to match the surrounding control or content.

## With content

Pass final content with `isLoading` to replace it in place. While loading, the spinner keeps the
content's dimensions and interactive descendants are unavailable. Set `isLoading` to `false` to
reveal the content.

## Colour

Omit `color` to inherit the surrounding text colour. Set it only when the spinner needs to match

## Accessibility

The spinner is a polite status region. Its accessible name defaults to `loading`. Provide an
`aria-label` that names the work, such as `Loading profile`. While loading, wrapped children are
hidden from assistive technology and cannot be focused or activated.

## With buttons

[`Button`](/components/actions/button) has its own `isPending` prop for a standard loading action.
For a labelled button that keeps its text visible, wrap the icon in `LoadingSpinner` and disable the
button while the action runs.
