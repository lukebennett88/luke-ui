title: Breakpoints
description:
  Change layout at a named viewport width, using the responsive value that every Sprinkles property
  accepts.
---

Luke UI defines six breakpoints. Every Sprinkles layout property, including `display`, accepts a
value for each one. Use a breakpoint to change layout at the point where it actually breaks, not by
default.

## Breakpoints

| Breakpoint | Minimum viewport width        |
| ---------- | ----------------------------- |
| `xsmall`   | None. This is the base value. |
| `small`    | 640px                         |
| `medium`   | 768px                         |
| `large`    | 1024px                        |
| `xlarge`   | 1280px                        |
| `xxlarge`  | 1536px                        |

Each breakpoint is a fixed constant, not a theme token. A custom theme cannot change these widths.

Every breakpoint is a minimum width. There is no maximum-width or range condition. A value set at
`medium` also applies at `large`, `xlarge`, and `xxlarge`, unless a later breakpoint overrides it.

## The responsive value API

Every Sprinkles property accepts a direct value or an object keyed by breakpoint. Values cascade up
from `xsmall`. Specify only the breakpoints where the value changes.

```tsx
<Box display={{ xsmall: 'none', large: 'flex' }} gap={{ xsmall: '200', medium: '400' }}>
	{children}
</Box>
```

This example hides an element below `large`, then shows it from `large` up. The same object form
works on every Sprinkles property, so a breakpoint can change spacing, direction, sizing, or
visibility together.

## When to use a responsive value

Set a responsive value only for a deliberate layout change, such as moving from a stacked to a
side-by-side arrangement, or hiding a decorative element on a small screen. Do not set one because
content might wrap.

Content that wraps well on its own, such as `flex-wrap` or a `minmax` grid track, needs no
breakpoint at all. Reach for a responsive value only once the layout actually breaks somewhere.

## Best practices

| Guidance | Practice                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| Do       | Change a value only at the breakpoint where the layout actually breaks.          |
| Don't    | Set a different value at every breakpoint out of habit.                          |
| Don't    | Reach for a responsive value when intrinsic wrapping already handles the layout. |
