Luke UI provides one spacing scale for `gap`, `padding`, and `margin`.

## The scale

The scale selects nine steps from a 4px linear scale. Each selected step maps to a fixed value. The
built-in themes share these values, so spacing does not change with the theme identity.

<ExampleBlock src="overview/spacing-scale" title="Spacing — Scale" />

## Responsive spacing

`gap`, `padding`, and `margin` accept an object keyed by breakpoint, cascading up from `xsmall`.

```tsx
<Box gap={{ xsmall: '300', medium: '600' }}>{children}</Box>
```

Read [Layout](/overview/layout) for Box, Sprinkles, and the full breakpoint list.
