title: Spacing
description: Space layouts with Luke UI spacing steps instead of fixed lengths.
---

Luke UI provides one spacing scale for `gap`, `padding`, and `margin`. The built-in themes use the
same values, so layout does not change with the theme identity.

## The scale

The scale has nine steps from `100` to `1600`. Each step maps to a fixed value owned by Luke UI.

<ExampleBlock src="overview/spacing-scale" title="Spacing — Scale" />

## Choose by relationship

Use the same step for the same relationship. Choose smaller steps for closely related elements and
larger steps between separate groups.

Set `gap` on a flex or grid parent to space its children. This keeps the relationship in one place.

<ExampleBlock src="overview/spacing-picker" title="Spacing — Compare steps" />

## Responsive spacing

`gap`, `padding`, and `margin` accept an object keyed by breakpoint, cascading up from `xsmall`.

```tsx
<Box gap={{ xsmall: '300', medium: '600' }}>{children}</Box>
```

Read [Layout](/overview/layout) for Box, Sprinkles, and the full breakpoint list.
