Luke UI uses cursor changes for links, text entry, and control states. Buttons keep the default
cursor.

| Convention           | Cursor        |
| -------------------- | ------------- |
| `Button`             | `default`     |
| `Link` or `Checkbox` | `pointer`     |
| `TextField`          | `text`        |
| Disabled control     | `not-allowed` |
| Pending `Button`     | `wait`        |

A `ComboboxField` uses text for its input, pointer for its action buttons, and default for its
options.

Move the pointer over each control to compare its cursor.

## Control states

Set `isDisabled` when an action is unavailable. The control leaves the focus order and blocks
interaction. Set `isPending` while a button action runs. The button remains focusable and blocks
further presses. Change its visible label when the status matters.

## Browser default cursors

The browser supplies the default cursor for non-interactive content. Do not add a pointer cursor to
content that does not respond to a press.

Luke UI ships no resizable component or resize cursor convention.
