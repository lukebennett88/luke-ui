Luke UI uses cursor changes to show the type and state of an interaction.

| Convention        | Cursor        |
| ----------------- | ------------- |
| Press action      | `default`     |
| Navigation link   | `pointer`     |
| Selection control | `pointer`     |
| Text entry        | `text`        |
| Disabled control  | `not-allowed` |
| Pending action    | `wait`        |

Move the pointer over each control to compare its cursor.

## Control states

Set `isDisabled` when an action is unavailable. The control leaves the focus order and blocks
interaction. Set `isPending` while an action runs. The control remains focusable and blocks further
presses. Change its visible label when the status matters.

## Browser default cursors

The browser supplies the default cursor for non-interactive content. Do not add a pointer cursor to
content that does not respond to a press.

Luke UI ships no resizable component or resize cursor convention.
