description: Public semantic CSS variables to build custom Luke UI elements.

`vars` is Luke UI's typed public token contract. Each path resolves to a stable `--luke-*` CSS
variable. For example, `vars.color.background.danger.solid.hover` resolves to
`var(--luke-color-background-danger-solid-hover)`.

Use these variables when a component API or layout utility cannot express a custom element. They
adapt to the active identity and colour mode.

## Use semantic variables

<ExampleBlock src="theming/semantic-variables" title="Token reference — Use semantic variables" />

Choose tokens by purpose. A card might use `surface.floating`, `radius.surface`, and
`depth.resting`. A warning message might use the warning role's subtle background and foreground. Do
not carry resolved colour values into application CSS.

## What stays private

The explorer lists the whole public styling API. These parts are internal, and they change without a
breaking release:

- The generated colour scales. `defineTheme` derives a full scale for each colour mode, and only the
  semantic tokens above name a step of it.
- Component recipe selectors and generated class names.
- Any `--luke-*` custom property that the explorer does not list.

Read a private value into application CSS and the element stops following the active identity and
colour mode.
